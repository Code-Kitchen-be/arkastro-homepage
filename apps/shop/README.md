# @arkastro/shop

Next.js storefront for the Custom Lab (Dutch UI, `be` region, ArkAstro brand tokens).

```bash
cp apps/shop/.env.template apps/shop/.env.local
# Set NEXT_PUBLIC_MEDUSA_PUBLISHABLE_KEY from Medusa Admin → Settings → Publishable API Keys
npm run dev:shop
```

Open http://localhost:8000 — default region `be`.
