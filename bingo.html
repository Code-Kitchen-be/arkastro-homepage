Hoe werkt het?

Bingo is een desktop-app voor de caller op een live event. Je werkt in één fullscreenvenster; spiegel (duplicate) het laptopscherm naar de projector via je besturingssysteem — er is geen apart publieksvenster.

  • Event starten
    Sluit de projector aan, spiegel het scherm, start Bingo en druk F11 voor fullscreen.
  • Platformen
    Windows en macOS (Apple Silicon). Broncode en updates via GitHub.
  • Eerste start
    Builds zijn niet digitaal ondertekend. Windows: SmartScreen → Meer info → Toch uitvoeren. macOS: rechtsklik → Open, of Gatekeeper omzeilen via Systeeminstellingen.
